\textbf{\Large Summary}

\vspace{1cm}

\begin{itshape}
This report presents the development of the \textbf{Infrastructure Command Center}, a unified web platform designed to centralize and optimize infrastructure management in an algorithmic trading environment. Faced with the fragmentation of monitoring, deployment, and performance tracking tools, this solution integrates essential functionalities for supervising and controlling critical systems within a cohesive interface.

The project was completed at \textbf{FinGenesis}, a Singapore-based company specializing in AI-driven algorithmic trading. This demanding professional context enabled the design of a tool that addresses real technical team needs while ensuring performance, reliability, and scalability.

Among its core functionalities, the Infrastructure Command Center offers:  
\begin{itemize}
    \item \textbf{Interactive visual workflows} enabling real-time system architecture visualization.  
    \item A \textbf{GitLab control panel} for managing repositories and triggering CI/CD pipelines directly from the interface.  
    \item An \textbf{MLOps dashboard} displaying AI model performance metrics with rolling accuracy and reference target comparisons.  
    \item \textbf{Performance optimization} reducing loading times by 96\% through intelligent caching and asynchronous processing.  
\end{itemize}

By combining React.js, FastAPI, and containerized infrastructure on AWS Kubernetes, this platform illustrates the application of modern DevOps and MLOps principles, drastically \textbf{reduces context switching}, \textbf{improves technical team productivity}, and centralizes critical system monitoring.

\noindent \textbf{Keywords:} Infrastructure Management, DevOps, MLOps, CI/CD, GitLab, React Flow, Performance Optimization, AWS, Kubernetes, FastAPI, Real-time Monitoring.
\end{itshape}
